# 0.1.0-alpha.5 功能与边界

本表区分当前入口已经提供的操作、需要额外工具的操作，以及尚未完成的能力。它不是全部输入格式、编码、版式或 macOS 版本的兼容性保证，也不是对 Tangerine 全部选项的等效验收。

当前分类器明确列出 82 个输入后缀（含别名）；对应菜单的 679 条转换方向均已有真实文件尝试。覆盖完整不等于全部通过，失败、拒绝与保真限制见下文及 [实际转换报告](ACTUAL-CONVERSION-REPORT.md)。

## 通用行为

- 工作台可多选、调整文件顺序和填写参数；轮盘按文件类型提供格式和工具入口。
- 混合文件选择只显示共同可用的动作。文件夹尚未开放给工作台和通用命令行入口。
- 输出默认放在原文件旁，遇同名文件自动换名，不覆盖原文件。
- 结果区区分成功、失败、取消和警告。已经成功生成的输出保留；取消不等于撤销已经完成的文件。
- 结果区置顶，显示完整路径、文件夹图片数量，提供 Finder 定位、打开和复制路径按钮。最近 12 个结果在本机保存，重启后可找回；已移动或删除的结果会显示不可用。
- 多页 PDF 转图片输出到原件旁的 `文件名 Pages` 文件夹，重复执行使用新编号，不覆盖现有结果。
- PDF 拆页/转多张图片与归档解压使用独立暂存目录，全部完成后才发布最终目录；失败时保留未完成材料并说明位置。部分其他操作也可能保留中间文件，当前没有统一自动清理入口。
- 当前主要验证环境为 Apple Silicon macOS。Intel、跨版本系统、各种第三方工具构建和完整拖放场景矩阵仍需补充验收。

## 图片

| 功能 | 当前行为 | 边界 |
| --- | --- | --- |
| 静态格式转换 | JPG、PNG、WebP、HEIC、TIFF、AVIF、BMP、PDF、DOCX 等按可用能力展示 | HEIC/AVIF 取决于系统或外部编码器；FFmpeg 的 AVIF 回退不能保留透明度，因此明确拒绝透明源并提示使用 PNG/WebP；不透明 AVIF 已实转验证 |
| 静态 WebP | 内置编码路径；可选 cwebp | 透明图片使用无损路径，不能用有损设置承诺更小体积 |
| GIF/APNG → WebP | 普通 GIF 优先 gif2webp；短帧 GIF 和 APNG 可用 cwebp + webpmux 逐帧编码，另有 FFmpeg 回退；已核验帧、时长及循环次数 | 依赖工具能力；含独立封面图的 APNG 明确拒绝，避免输出错误画面 |
| GIF → MP4 | 将动画导出为视频 | 动画循环语义和视频播放次数不是同一概念；不保证全部动画变体兼容 |
| 多页 TIFF | 转 PDF/DOCX 保留全部页面 | 转单张图片明确拒绝，不静默只取第一页 |
| EXR | 系统无法解码时可使用 FFmpeg，先转为 16 位 RGBA 中间图像 | 不承诺保留完整浮点 HDR 动态范围或专业色彩信息 |
| 等比缩放 | 在指定宽高范围内保持比例，输出 PNG | 单维为 0 表示该维不限；并非强制拉伸为指定比例 |
| 拼图 | 按工作台文件顺序排列，设置列数、单元格尺寸和间距 | 输出静态 PNG；不作为动画拼接工具 |
| 二维码识别 | 识别内容后保存 TXT | 没识别到时明确失败；不承诺识别所有模糊、扭曲或遮挡的码 |
| 目标大小 | 保持像素尺寸，以实际编码字节核验目标 MB | MB 为十进制；透明图使用无损 PNG/WebP，非透明图可搜索 JPEG 质量；达不到就报错，不偷偷缩小像素尺寸 |
| 编辑与保护 | 裁剪、旋转/调整、标注、背景、遮挡、元数据查看/处理 | 尚无全面色彩管理、专业修图或全部元数据字段保真验收 |
| 图片 → DOCX | 页面图片加 OCR 文本 | macOS 文本编辑只读 OCR 文字、不显示图片；OCR 失败会报告；识别准确率不保证，复杂排版不能还原成原生 Word 结构 |

动图压缩明确拒绝，避免把首帧当作完整动画压缩结果。将动画转换为本身不承载动画的静态格式不能保留动画，当前不应把这类路径当作动画备份；静态图像工具也不等于逐帧编辑工具。

RAW 不能仅凭后缀判断兼容性：Fuji S5000（RAF）、Olympus E-10（ORF）、Samsung NX500（SRW）实测各 9 种输出仍失败，共 27 次；其他机型的同后缀样例已通过，不能因此宣称所有 RAF/ORF/SRW 均可用。

**SVG 未实现：** 当前明确拒绝 SVG 输入渲染和 SVG 输出矢量化，不把嵌入位图的 SVG 文件冒称为矢量转换。

## PDF 与文字文档

| 功能 | 当前行为 | 边界 |
| --- | --- | --- |
| PDF → JPG/PNG | 按页输出；多页输出到目录 | 光栅化有分辨率和内存限制，不保留矢量编辑性 |
| PDF → TXT | 优先读取文字层，扫描页尝试 OCR，并保留已填表单文字 | 扫描底图和表单同时存在时仍识别正文；文本框中的字面值 `Off` 保留。无正文、OCR 和表单文字的页明确失败；OCR 结果需复核，无法恢复原版式 |
| PDF → DOCX：页面外观 | 手动选择后逐页以 150 DPI 图片嵌入 Word；macOS 文本编辑无法显示这些图片 | 图表外观随页面保留，但正文不能直接编辑；页面被缩放到 Word 页面可用区域，不能称为无损或原尺寸复刻 |
| PDF → DOCX：可编辑文字 | 默认；文字层重建段落，扫描页尝试 OCR；空识别明确失败 | 复杂分栏、表格、图片、图表及原排版可能丢失或重排 |
| 合并 | 按 Finder 文件名排序合并 PDF；图片也可按文件名合成 PDF | 与影音拼接、图片拼图的输入顺序规则不同 |
| 拆页、旋转、重排 | 拆为单页 PDF；旋转；按页码导出新 PDF | 重排例 `3,1-2,5-4`；支持重复页，未列出的页不进入输出，原文件保留 |
| 压缩、水印、元数据 | PDF 压缩、文字水印、元数据查看/处理 | 不保证压缩后必然更小；加密/损坏或无法读取的文件会失败 |
| 富文本转换 | 读取 DOC/DOCX、RTF、ODT、HTML、TXT、Markdown 等，输出支持的 PDF/DOCX/RTF/ODT/HTML/TXT/Markdown | 使用系统文档导入导出；不是 Microsoft Office 排版引擎 |
| RTFD/Webarchive | 纯文字样例的全部 7 种输出均通过；附件图片在 PDF 和自包含 HTML 中保留 | 含图片时 DOCX/RTF/ODT 输出明确拒绝；TXT/Markdown 不能保留图片，不计图片保真通过 |

扫描 PDF 的 OCR 准确率、混合语种、复杂表格、数学公式及跨系统兼容性尚未充分验收。错误会向用户报告，但识别成功不等于文字逐字正确。

DOCX 段落样式定义的标题字号、继承样式及普通列表符号丢失问题已修复并实测。含有页眉页脚（含纯图片）、脚注/尾注、公式或未实现的复杂编号的 DOCX 当前明确拒绝，避免静默丢内容；含嵌入图片的 DOCX 转 PDF/RTF/HTML/ODT 也明确拒绝。TXT/Markdown 可保留正文，但图片与表格结构不作保真承诺。当前没有完整 DOCX/ODT 高保真承诺，也未提供 Excel 或 PowerPoint 全格式转换。

已填写的 PDF 表单会进入图片和页面外观输出，文字输出也保留字段值；6 项表单外观对照仍有文字纵向位置差异，列为有限保真。部分 PDF 提取汉字会成为 Unicode 兼容部首，规范化后内容一致但原码位不同。

## 影音

| 功能 | 依赖与行为 | 边界 |
| --- | --- | --- |
| MP4/MOV 与基础工具 | 系统可读时优先使用 AVFoundation；提供转换、剪辑、静音、旋转、截图和压缩 | 容器能打开不代表其中每种编码都可处理；可直拷时尝试直拷，否则可能重新编码 |
| 更多视频格式 | FFmpeg 提供 MKV、WebM、AVI、WMV 等路径 | 依赖其实际编码器；不能只凭安装了 FFmpeg 就承诺支持 |
| 音频转换/提取 | M4A、WAV、AIFF、FLAC；MP3、OGG、Opus、WMA 等使用可选 FFmpeg | 输出容器与编码有区别；当前 OGG 路径使用 Opus，不是 Vorbis |
| 视频 → GIF | 按帧转换，默认保护上限 30 秒 | 超过限制会拒绝并要求先剪辑，不静默截断；并非长视频高质量存档方案 |
| 变速 | FFmpeg + ffprobe，支持 0.125–8 倍 | 输出重新编码；声音与画面同时调整 |
| 影音拼接 | FFmpeg + ffprobe，按工作台/命令行输入顺序 | 视频统一到首个视频尺寸、30 fps；音频统一为 48 kHz 立体声，缺失音轨的片段补静音；不是无损拼接 |
| 分段 | FFmpeg + ffprobe，按指定秒数分段，最多 1,000 段 | CLI 用 `--end` 指定段长；每段重新编码，失败或取消时保留并在结果中列出已完成分段，当前输入不算全部成功 |
| 视频裁剪 | FFmpeg + ffprobe，设置像素位置与宽高 | 裁剪框须在画面内，宽高使用正偶数 |
| 音量标准化 | FFmpeg + ffprobe，响度目标约 -16 LUFS | 当前为单次滤镜处理，不作为广播级两遍响度验收结果 |
| 提示音遮盖 | FFmpeg + ffprobe，将指定区间原音静音并叠加提示音 | 按秒指定区间；不是自动识别人声或敏感词 |
| 单/双声道 | FFmpeg + ffprobe，输出单声道或立体声 | 不提供完整多声道保真或独立轨道编辑 |
| 目标大小 | FFmpeg + ffprobe，基于时长估算码率，再核对实际输出字节 | 会重新编码；过小或无法满足的目标明确失败，不保证固定画质 |

**高级影音操作及部分格式转换仅处理第一路视频/音轨。** 字幕流、附加音轨、封面、章节及附件不保证保留。需要这些内容时，不应把当前输出当作完整媒体归档。高级操作通常输出 MP4 或 M4A；原格式、码率、色彩、HDR、多轨信息不保证保留。

## 字幕

- 输入为已有时间轴的 SRT 或 VTT；支持 SRT/VTT 互转与 TXT 导出，保留毫秒时间戳、多行和 Unicode 文本。
- TXT 没有时间轴，不会凭空生成“真实对齐”字幕；当前没有语音自动转写/对齐入口。
- VTT 的 STYLE、REGION、定位设置等不能完整保留时会拒绝转换。该实现不等于完整 WebVTT 排版引擎，也不支持 ASS/SSA 全样式互转。
- 非法时间戳、结束早于开始、缺少有效内容等会报告错误，不自动猜测修复。

## 压缩包

- 当前应用入口提供 ZIP、TAR、GZIP 的互转，以及支持归档的解压。GZIP 是单一数据流，多文件归档转 GZIP 会输出 `.tar.gz`。
- 底层模块具备普通文件/目录打包能力，但当前工作台和通用命令行尚未开放文件夹打包或任意文件“一键压缩”。
- RAR 只尝试 macOS 系统 libarchive 能读取的变体；压缩 RAR5 和 solid RAR5 转 ZIP/TAR/GZIP 已用真实样例通过，仍有被拒绝的 RAR 变体。不支持 RAR 创建，不承诺全部 RAR、加密或分卷变体。
- 解压拒绝父级路径、绝对路径、符号链接、硬链接、特殊文件、冲突文件名与目录/文件冲突。输出采用新的受限权限文件，不恢复归档中的所有者或可执行权限。
- 默认上限：10,000 条目、每文件 512 MiB、总展开 1 GiB、目录深度 128 层。展开比按压缩文件大小的 200 倍计算，前 16 MiB 作为容许量；达到任一适用限制会停止，不继续生成伪完整结果。
- 当前采用保守限制，可能拒绝合法的大归档或包含链接的开发项目。失败会保留隔离的未完成目录，不代表整个解压已经成功。

## 尚未完成的发布验收

完整商业软件替代所需的逐项功能对照、大型真实样本集、长期批量稳定性、性能与内存基准、Intel/macOS 版本矩阵、扫描文档 OCR 质量、复杂 Office 保真、全部动画/编解码变体和系统拖放场景仍需继续验证。

源码已在公开仓库发布；当前构建包仅有 ad hoc 本机签名，未经过 Apple 公证，尚无正式安装包发布通道。实际转换验收见 [实测报告](ACTUAL-CONVERSION-REPORT.md)；完整发布仍需核对上述范围与外部安装体验。
